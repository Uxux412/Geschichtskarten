# Geschichtskarten

Interaktive Karten für den Geschichtsunterricht: Frankreich unter Ludwig XIV., Revolution und Napoleon, Zweiter Weltkrieg, Europa nach 1945, Weg zur Teilung, Mauerbau.

App: https://uxux412.github.io/Geschichtskarten/

Diese Dateien werden aus dem Ordner `geschichtskarten/` des Repositorys `unterricht` gebaut (`python3 build.py`). Änderungen dort vornehmen und `index.html` hierher kopieren.

Kartengrundlage: Natural Earth (gemeinfrei). Schriften: Barlow Semi Condensed, Source Serif 4 (SIL Open Font License). QR-Erzeugung: qrcode-generator von Kazuhiko Arase (MIT).
